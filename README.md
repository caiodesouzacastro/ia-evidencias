# Verificar antes de confiar

Página de apoio do curso «Verificar antes de confiar. IA aplicada ao trabalho com evidências», para técnicos dos PALOP.

- `index.html`: a página, num só ficheiro: o curso, a preparação e o teste de acesso, os pacotes para descarregar, os checklists, os pedidos que funcionaram, o glossário e as fontes oficiais.
- `downloads/`: o programa do curso em PDF e os três pacotes dos participantes (preparação, Dia 1, Dia 2).

Publicada pelo GitHub Pages.
