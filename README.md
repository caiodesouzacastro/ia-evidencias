# IA para quem trabalha com evidências

Página de apoio do curso «IA para quem trabalha com evidências. Curso prático para gestão pública, avaliação e investigação»: o kit dos inscritos nos dois módulos, para profissionais que trabalham com evidências nos PALOP. Instrutor: Caio de Souza Castro (FGV EESP e FGV CLEAR).

Publicada em <https://caiodesouzacastro.github.io/ia-evidencias/>.

- **Módulo 1 · Básico** (2h30): o que é a IA, vantagens e limites, ética e uso responsável, pedir bem e prática em grupos com tarefas padrão. Para quem usa pouco ou nunca a IA.
- **Módulo 2 · Intermediário** (2h30): conceitos intermediários, documentos fechados e síntese de evidências, teoria da mudança e indicadores, análise qualitativa e comunicação de evidências. Funciona sem o Módulo 1.

Conteúdo:

- `index.html`: a página, num só ficheiro: Apresentação (o que é cada módulo, para quem, o que se leva), Preparação (instruções curtas para os inscritos), Módulo 1, Módulo 2, Para ler depois (o rascunho de trabalho do Global Evaluation Initiative, só pelo link oficial) e Checklists e pedidos. Em cada módulo: objetivos, programa, slides, folhas, respostas gravadas, fontes e o pacote completo.
- `downloads/`: o programa do curso (uma página por módulo), os três pacotes (preparação, Módulo 1, Módulo 2) e, em subpastas, os mesmos ficheiros soltos: `slides/`, `folhas/`, `demonstracoes/`, `extratos/` (só o A1 e o A4, que o autorizam) e `apoio/`.

Gerada a partir do repositório do curso com `scripts/gerar-pagina.py`. Publicada pelo GitHub Pages.
