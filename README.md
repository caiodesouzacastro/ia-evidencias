# Verificar antes de confiar

Página de apoio do curso «Verificar antes de confiar. IA aplicada ao trabalho com evidências», para técnicos dos PALOP. Instrutor: Caio de Souza Castro (FGV EESP e FGV CLEAR).

- `index.html`: a página, num só ficheiro, pela ordem do curso: Apresentação, Preparação (programa, teste de acesso, glossário), Dia 1, Dia 2, Extensão (pré-escola em Gaza), Checklists e pedidos que funcionaram. Em cada dia: blocos, slides, folhas, demonstrações, fontes oficiais pela ordem dos blocos e o pacote completo.
- `downloads/`: o programa do curso, os três pacotes (preparação, Dia 1, Dia 2) e, em subpastas, os mesmos ficheiros soltos: `slides/`, `folhas/`, `demonstracoes/`, `extratos/` (só o A1 e o A4, que o autorizam) e `apoio/`.

Gerada a partir do repositório do curso com `scripts/gerar-pagina.py`. Publicada pelo GitHub Pages.
